## 🧭 Overview

**A11yBonjour** is a mini-landing page showcasing the philosophy of **A11yBonjour**,  
the accessibility-focused company founded by **Adrien Calvez-Foubert**.  
It embodies his core values: clarity, empathy, and inclusion.

Accessible, responsive, and bilingual (🇬🇧 / 🇫🇷), it combines:

- semantic HTML and precise ARIA landmarks,  
- mobile-first CSS with light/dark modes,  
- accessible JavaScript micro-interactions,  
- and a touch of React for two living components: *Pink Noise* and *Scroll to Top*.

---

## ✨ Features

- ♿ **Accessibility First** — keyboard nav, screen readers, aria-live, visible focus  
- 🌓 **Light/Dark theme toggle** — respects user system preferences  
- 🌬️ **Pink Noise Player** — gentle relaxation, fully keyboard accessible  
- 🌤️ **Weather widget** (React) — OpenWeather API, bilingual  
- ✅ **To-do list** — persisted with localStorage, semantic & responsive  
- 🧩 **A11Y Audit accordion** — bilingual dynamic content  
- 🌍 **Language toggle (EN/FR)** — instant, no reload  
- 🖼️ **Memphis + Minimal aesthetic** — contrast, rhythm, breathing space  
- 🔒 **Privacy by design** — 100% local storage, no data tracking

Elle reflète ses valeurs : clarté, empathie et inclusion.
