## Overview

A calm, accessible, **Human + AI** site with native fallbacks and small, focused demos.  
Dark-first, local-first, and privacy-respectful.

- **Home**: semantic HTML + vanilla JS  
- **/lab**: React islands (UMD), each with an accessible HTML fallback

## Highlights

- **Progressive enhancement**: native first, modern when available
- **React as islands** (UMD on /lab), not a SPA
- **View Transitions**, **Popover**, **Container Queries**
- **Scroll-driven animations** (respect RMW)
- **Web Audio** (local pink/white/brown noise + timer)
- **Web Speech** (local TTS presets, FR/EN aware)
- **Local-first privacy**: *AOHZY runs locally — no cloud, no tracking*

## Accessibility

- Keyboard-first interaction & visible focus rings  
- ARIA where it adds value (combobox/dialog demos)  
- Respects `prefers-reduced-motion`  
- High contrast dark theme (AA/AAA oriented)

## Performance & Budgets

- HTML < 30 KB • CSS < 20 KB • JS (home) < 50 KB  
- System fonts • No tracking scripts • No heavy frameworks on home
